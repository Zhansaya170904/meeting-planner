# Meeting Planner

A web-based meeting management system built with PHP and MySQL.

The application allows users to create and manage meetings, organize tasks, view meetings in a calendar, manage meeting minutes, and work with different user roles.

## Features

- User registration and login
- User profile management
- Role-based user system
- Create, edit and delete meetings
- View meeting details
- Meeting calendar
- Task management
- Meeting minutes
- Notifications
- Participant management
- Password hashing for user accounts
- MySQL database integration

## Tech Stack

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- XAMPP
- Apache
